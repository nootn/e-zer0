# Security policy

Please report suspected vulnerabilities privately to **nootn@hotmail.com**,
the security contact for e-zer0 maintainer Andrew Newton (GitHub: `nootn`).

Include the affected commit, reproduction steps using synthetic data, expected
and actual behaviour, and the potential impact. Do not send real mailbox
content, access tokens, passwords or other credentials. Please keep unpatched
vulnerabilities out of public issues and pull requests while we assess them.

Security fixes target the current `main` branch. This project does not currently
maintain separate supported release branches.
